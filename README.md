# 信息自填页面示例

这是一个可在手机微信浏览器中打开的静态页面模板，用于自填信息展示。页面包含明显的“非官方示例模板”提示，不具备任何验证、查询或证明效力。

## 使用方式

1. 直接用浏览器打开 `index.html`。
2. 点击页面中的文字字段即可修改内容。
3. 点击照片区域可以选择本地图片。
4. 修改后的内容会自动保存在当前浏览器的 localStorage 中。

## 文件

- `index.html`：页面结构
- `page01.html` - `page10.html`：10 份独立页面
- `data/page01.json` - `data/page10.json`：10 份独立默认数据
- `style.css`：移动端样式
- `app.js`：字段保存和照片上传
- `photo-placeholder.svg`：默认照片占位图

## 修改 10 份默认内容

编辑 `data/page01.json` 到 `data/page10.json` 中对应字段，提交并推送后，别人打开对应页面会看到新的默认内容。
